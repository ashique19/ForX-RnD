# Sketch - Cross-pair disagreement veto (research design only) - 2026-10-01 Asia/Dhaka
Standing ForX autonomy. **Default OFF. No Replay. No promote path.**

## Observation
Multi-pair pins (EUR/JPY/GBP/AUD/NZD/CAD) all fire USD-beta heavy books. Simultaneous USD-cross BUY/SELL can stack the same USD risk. Portfolio-brain corr veto (disabled) is the intended home; this note sketches a lighter **signal disagreement** rule.

## Idea (v0)
When Active=EURUSD is about to open:
- Peek latest flash/side for USDJPY, AUDUSD, GBPUSD, NZDUSD, USDCAD (research watchlist).
- Map each to USD-risk direction (same map as `portfolio_brain._USD_RISK_LONG`).
- If >=2 other pairs disagree with EURUSD's implied USD risk (opposite sign) at conf>=0.70, **veto** the EURUSD open (HOLD) - treat as USD regime conflict.
- Fail-soft if peer flash missing / low conf / unknown pair.
